# CLI Todo App

A simple Command Line Interface (CLI) Todo Application that allows users to create, read, update, and delete todo items.

## Features
- Create new todo items
- List all todo items with completion status
- Update existing todo details
- Delete todo items
- Persistent storage to ensure data is retained between sessions

## Installation
Just clone the repository and run the `todo_app.py` file using Python.

## Usage
Run the app and use the following commands:
- `add`: Create a new todo.
- `list`: Show all todos.
- `update`: Modify an existing todo's details.
- `delete`: Remove a todo.
- `quit`: Exit the application.

## Requirements
- Python 3.x
- json module (included in the standard library)
