# SDD Commands

This project supports three main SDD commands for demo use:

- `/spec` prepares a short task specification before implementation.
- `/changes` prepares a change set or implementation plan for a broader update.
- `/drafts` prepares a targeted draft for an existing file or function.

Simple examples:

- `/spec prepare spec for adding detailed logging to search_in_repo`
- `/changes create helper to export repo manifest summary as markdown`
- `/drafts add more detailed logging to existing search_in_repo in tools/repo_tools.py`

Ukrainian note:

- Основні команди для SDD: `/spec`, `/changes`, `/drafts`.
- `/spec` готує коротку специфікацію перед реалізацією.
- `/changes` готує набір змін або план реалізації.
- `/drafts` готує точкову чернетку для існуючого файлу або функції.
