# Команди SDD

У цьому проекті основні команди для SDD такі:

- `/spec` готує коротку специфікацію задачі перед реалізацією.
- `/changes` готує набір змін або план реалізації для ширшої зміни.
- `/drafts` готує точкову чернетку для існуючого файлу або функції.

Короткі приклади:

- `/spec підготуй специфікацію для додавання більш детального логування в search_in_repo`
- `/changes create helper to export repo manifest summary as markdown`
- `/drafts add more detailed logging to existing search_in_repo in tools/repo_tools.py`

Коротка відповідь на запитання "які в тебе є команди для sdd?":

- Для SDD доступні `/spec`, `/changes`, `/drafts`.
