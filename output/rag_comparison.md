# Порівняння Naive RAG та Sentence-Window Retrieval

## Вступ
Retrieval-Augmented Generation (RAG) - це підхід, що поєднує генерацію тексту з зовнішнім пошуком інформації. Існує кілька архітектур RAG, серед яких Naive RAG та Advanced RAG, що включає метод Sentence-Window Retrieval.

## Naive RAG
- **Опис**: Naive RAG є найпростішою формою RAG, де система отримує релевантну інформацію з бази знань і передає її безпосередньо до мовної моделі (LLM) для генерації відповіді.
- **Процес**: Складається з чотирьох основних етапів: індексація, пошук, доповнення та генерація.
  - **Індексація**: Підготовка та організація даних.
  - **Пошук**: Кодування запиту у вектор та знаходження найбільш релевантних частин тексту.
  - **Доповнення**: Поєднання запиту з отриманими даними.
  - **Генерація**: Використання доповненого контексту для створення відповіді.
- **Обмеження**: Може генерувати неточні відповіді через відсутність контексту.

## Sentence-Window Retrieval
- **Опис**: Це вдосконалений підхід, що покращує контекст, наданий LLM, шляхом отримання не лише одного речення, а й сусідніх речень.
- **Процес**: Під час пошуку система отримує "вікно" речень, що оточують найбільш релевантне речення, що дозволяє LLM мати більше контексту для генерації.
- **Переваги**: 
  - Підвищує релевантність відповідей на 22.7%.
  - Підвищує обґрунтованість відповідей на 38.2%.
  - Зменшує загальну кількість токенів, що генеруються.

## Порівняння
| Характеристика               | Naive RAG                          | Sentence-Window Retrieval         |
|------------------------------|------------------------------------|-----------------------------------|
| Простота                     | Висока                             | Середня                           |
| Релевантність відповідей      | Низька до середньої               | Висока                            |
| Кількість контексту          | Обмежена                          | Розширена                         |
| Витрати на обчислення       | Низькі                             | Вищі                             |

## Висновок
Naive RAG є простим і ефективним рішенням для базових завдань, але має обмеження в контекстуалізації. Sentence-Window Retrieval пропонує значні покращення в якості відповідей завдяки більшому контексту, що робить його кращим вибором для складніших завдань.
